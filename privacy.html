PowerDial Privacy Policy

Last updated September 24, 2026

PowerDial is a desktop app used privately by one health-insurance agent. This policy explains how it uses Google user data.

What Google data PowerDial accesses

Only Google Calendar, with two permissions: seeing the list of calendars the agent can use (calendar.calendarlist.readonly) and creating or updating events (calendar.events).

How it is used

PowerDial creates an appointment on a calendar only when the agent picks a time and clicks Schedule and then Confirm. It reads the calendar list only so the agent can choose where the appointment goes. It does not read, change, or delete any other events.

Where it is stored

The Google sign-in token is kept encrypted on the agent's own computer using the operating system's secure storage. Nothing is stored on any PowerDial server; there isn't one.

Sharing

Google user data is not sold, shared with, or transferred to anyone, and is not used for advertising or to train AI models. PowerDial's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from PowerDial (Settings → Google Calendar → Disconnect) or at myaccount.google.com/permissions.
